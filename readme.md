# SmartBus 🚌

Sistema de gestión de buses en tiempo real con localización de conductores.

## Características ✨

- 🗺️ Rastreo de ubicación en tiempo real de buses
- 👥 Gestión de usuarios, conductores y buses
- 🚌 Control de rutas y paradas
- ⚠️ Reportes de incidentes en carretera
- 💬 Sistema de quejas y sugerencias
- 📊 Panel de administración

## Tecnologías 🛠️

- **Backend:** FastAPI + Python
- **Base de datos:** PostgreSQL
- **Frontend:** HTML5 + JavaScript + PWA
- **Hosting:** Render.com

## Instalación local 💻

### Requisitos previos
- Python 3.8+
- PostgreSQL
- Git
